### Recording Tips:
- Aim for a confident, conversational tone
- Record in vertical format (9:16 aspect ratio) for mobile optimization
- Use neutral background or subtle matrix-style elements if possible
- Keep consistent lighting and audio across all segments
- Leave 1-2 seconds of silence at beginning/end of each clip for smooth transitions
