# $CLAUD Protocol Website


## Overview

This website features:
- Vertical-format video presentation
- Synchronized content expansion
- Matrix-style falling character animation
- Dynamic word formation effects
- Reactive background elements
- Mobile-first responsive design

## Quick Start

1. **Clone the Repository**
   ```bash
   git clone https://github.com/seanivore/claud-web.git
   cd claud-web
   ```

2. **Local Development**
   - Open `index.html` in your browser
   - For live reload, use a local server:
     ```bash
     npx http-server
     ```

3. **Deployment**
   - Site auto-deploys to GitHub Pages
   - Main branch updates trigger deployment
